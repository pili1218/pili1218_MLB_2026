Root cause: a massive OVER-prediction bias, not bad luck
Over the last 40 O/U games the model predicted OVER 33 times (82.5%) — but actual games went OVER only 17 times (42.5%). That's a +40 percentage-point directional bias. Of the 33 OVER calls, 21 lost (game went UNDER), with the final total coming in an average of 3.4 runs below the line — 9 of them missed by 4+ runs. This is not variance; it's a stale scoring assumption. GVI 65–80 band: model predicted OVER 12/13, actual OVER only 3/13.
Fix applied: OVER_RATE_GATE emergency warning now injected into every prediction when actOV <45%
When rolling 5-day actual-OVER rate falls below 45%, the server now injects a hard-to-miss caution block into the prediction context (before game data), explicitly suppressing GVI-only OVER calls and defaulting the O/U lean to UNDER. Three-pronged fix: (1) OVER_RATE_GATE warning injection, (2) GVI≥65 no longer standalone OVER catalyst — requires OU-B wind or Slumping SP, (3) UNDER as default lean when environment is compressed.
